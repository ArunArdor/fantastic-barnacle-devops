# 🏐 SpikeTrack — Volleyball Practice Attendance

SpikeTrack is a full-stack web application designed to track attendance for volleyball practice sessions.  
Players can log in, check in for practice, update their status, and view the live team roster.

This project was built for the **CIS 486 course** and demonstrates a full-stack application using Node.js, Express, and MongoDB Atlas.

## 📌 Features

- Player login system
- Practice check-in
- Live roster of players
- Edit attendance status
- Remove players from roster
- Quick check-in for the logged-in player
- Real-time practice statistics
- Toast notifications for user actions
- Responsive modern UI
